我给自己的首页换了一块草地

从信息架构开始重做一个个人站，关于留白、节奏，以及如何不把自己藏在组件后面。

2026.09.28约 8 分钟1,248 次浏览状态：已发布

我想要一个打开就能认出“这是我的地方”的首页。不是一张漂亮的封面，也不是把所有经历塞进一排卡片，而是一小块可以慢慢走进去的地形。

先把入口变得诚实

旧首页的问题很具体：文章被藏在第二屏，项目和个人介绍没有顺序，第一次来的人要靠猜。于是我先把最常用的三件事放在第一视线里：我在写什么、最近做了什么、从哪里继续往下走。

好的首页不是把所有信息都展示出来，而是给下一步一个清楚的方向。

用材质建立层次

像素风并不等于把每个元素都做成方块。我只保留三种材质：草地负责背景，木牌负责导航，石头负责内容容器。透明度让它们叠在一起，像游戏里不同高度的方块。

const surface = {
  background: 'rgba(14, 31, 53, .79)',
  border: '2px solid rgba(174, 208, 235, .25)',
  shadow: '6px 6px 0 #08101d'
}

让转场像走过一扇门

进入页面时，导航、标题和正文按地形顺序落下；切换昼夜时，只有一层短暂的光闪过。动作很短，但它们告诉你世界发生了变化，又不会抢走文章本身的注意力。

最后留下可继续建造的空间

这版首页完成后，我还留了几个空槽：搜索结果的空状态、文章目录、以及把阅读进度变成一条细细的经验条。它们不急着今天完成，但下一次打开编辑器时，我知道从哪一块继续。
